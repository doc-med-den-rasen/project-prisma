# Grabber-TXT-Beispiele

Hier können kleine, vollständig anonymisierte Grabber-TXT-Testfälle abgelegt werden.

Bitte keine Patientennamen, Geburtsdaten, Patientennummern, Benutzernamen oder andere rückverfolgbare Daten einchecken. Frühere XLSX-Beispiele liegen nur noch im Archiv unter `archive/xlsx/samples/`.
